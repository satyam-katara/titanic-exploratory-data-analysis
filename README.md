# Titanic Exploratory Data Analysis

An exploratory data analysis project on the **Titanic dataset** using Python, Pandas, Matplotlib, and Seaborn.

## 📌 Project Overview

The goal of this project is to explore the Titanic dataset, understand the characteristics of the passengers, identify patterns related to survival, and perform basic data preprocessing.

## 🎯 Objectives

- Understand the structure and characteristics of the Titanic dataset
- Perform data cleaning and preprocessing
- Analyze numerical and categorical variables
- Explore relationships between passenger features and survival
- Identify patterns and trends through visualization
- Practice fundamental Exploratory Data Analysis (EDA) techniques

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**
- **Jupyter Notebook**

## 📊 Analysis Performed

The notebook covers:

- Dataset shape and structure
- Data types and basic information
- Missing-value analysis
- Descriptive statistics
- Univariate analysis
- Categorical variable analysis
- Numerical variable distributions
- Survival analysis
- Data visualization
- Basic preprocessing

## 📚 Dataset

The project uses the **Titanic dataset**, containing information about passengers such as:

- Passenger Class
- Sex
- Age
- Fare
- Number of Siblings/Spouses
- Number of Parents/Children
- Embarkation Port
- Survival Status

## 🔍 Key Questions

Some of the questions explored in this project include:

- What percentage of passengers survived?
- How does survival vary by gender?
- How does passenger class relate to survival?
- What is the distribution of passenger ages?
- How are numerical variables distributed?
- Which variables contain missing values?
- What patterns can be observed between passenger characteristics and survival?

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/satyam-katara/titanic-exploratory-data-analysis.git
```

Navigate to the project directory:

```bash
cd titanic-exploratory-data-analysis
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Open the notebook:

```bash
jupyter notebook Titanic_EDA_and_Preprocessing.ipynb
```
